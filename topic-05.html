Topic 5: Arrays & Collections

Array, List, Dictionary, LINQ basics

Arrays and collections store groups of values. Arrays have fixed size, while List and Dictionary grow dynamically. LINQ provides a declarative way to query, filter, and transform collections using method syntax (Where, Select, OrderBy) or query syntax (from ... where ... select).

Key Concepts

  • Arrays are fixed-size, zero-indexed, and can be single or multidimensional
  • List is a generic, resizable array backed by an internal array
  • Dictionary stores key-value pairs with O(1) lookup
  • Queue is FIFO; Stack is LIFO
  • HashSet stores unique elements with O(1) contains checks
  • LINQ method syntax uses extension methods like .Where().Select()
  • LINQ query syntax uses from, where, orderby, select keywords
  • Array.Copy and Array.Resize manipulate array contents
  • Collection initializers let you populate collections inline
  • Index and Range operators ([^1], 0..3) simplify array slicing

Quick Questions & Answers

Q1: What is the difference between an array and List?
A: Arrays have fixed size; List is a dynamic, resizable collection that internally uses an array and copies elements when capacity is exceeded.
Q2: How does Dictionary handle hash collisions?
A: It uses chaining (linked lists per bucket) or open addressing depending on the .NET version; collisions degrade lookup from O(1) to O(n) in the worst case.
Q3: What is the difference between List.Add and List.Insert?
A: Add appends to the end; Insert places an element at a specific index, shifting subsequent elements.
Q4: How do you iterate over a Dictionary?
A: Use foreach with KeyValuePair, or iterate over dict.Keys or dict.Values directly.
Q5: What does LINQ's .Select() do?
A: It projects each element into a new form by applying a transform function, returning an IEnumerable of the projected type.
Q6: When should you use a HashSet?
A: When you need fast O(1) membership checks and want to ensure uniqueness without storing duplicate values.
Q7: What is the difference between Queue and Stack?
A: Queue is first-in-first-out (FIFO); Stack is last-in-first-out (LIFO).
Q8: How do you sort an array in place?
A: Use Array.Sort(arr) or arr.Sort() for a List.
Q9: What does the 'from' keyword do in LINQ query syntax?
A: It introduces a range variable that iterates over the source collection, similar to foreach.
Q10: How do you remove all elements matching a condition from a List?
A: Use list.RemoveAll(predicate) which removes all elements for which the predicate returns true.
